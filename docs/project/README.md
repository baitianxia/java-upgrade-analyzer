# 项目文档

本目录回答“当前从哪里开始、后续可能做什么、过去的设计和审计说明了什么”。它不拥有永久系统语义。

## 日常入口

- [当前工作上下文](current.md)：维护和开发的唯一导航入口。
- [Roadmap](roadmap/README.md)：候选工作与进入条件，不直接授权编码。
- [开发记录](iterations/README.md)：按时间保留设计与实施计划。
- [审计记录](audits/README.md)：有明确基线和适用边界的项目证据。
- [文档治理](governance/README.md)：信息归属、状态和迁移规则。

实现或审计发现若改变当前系统真相，应在同一变更中回写 `docs/system/` 的唯一所有者文档；只影响后续机会的内容进入 Roadmap。

# 产品定位与能力边界

`java-upgrade-analyzer` 是给 Claude Code 使用的 Java 升级兼容性分析 Skill。它以升级前后最终制品、目标 JDK、源码覆盖和可复核调用关系为证据，判断运行平台、框架、规范迁移或依赖变化是否触达当前业务系统。

## 当前能力

- 比较 base/current 最终制品和运行时依赖身份；
- 识别依赖 API、数据契约、JDK、框架与 `javax.*` → `jakarta.*` 变化；
- 使用 binary-first 引擎分析业务入口到变化 API 的静态触达路径；
- 用 Markdown、CSV 和结构化证据输出依赖级、API 级结论及范围限制；
- 支持已完成 Step5 结果的只读调用链查询。

## 明确边界

- 默认只分析和报告，不自动修改用户代码；
- 静态分析不冒充业务运行验证，不输出伪造的 `confirmed_impact` 或 `confirmed_no_impact`；
- 源码用于解释和定位，最终制品及目标运行时才是依赖、类、API 和可执行边的事实主线；
- 证据覆盖不足时必须限制结论，不能把“未分析”或“静态未找到”写成安全。

面向使用者的完整输入、交互与示例见仓库根目录[使用说明](../../../README.md)。

# 运行与结果阅读

本目录面向使用者、人工复核人和维护运行流程的工程师。

- [用户输出说明](outputs.md)：`.upgrade-report/` 的交付、证据、程序状态与推荐复核顺序。
- [`README.md`](../../../README.md)：快速开始、输入、交互、结果和常见问题。
- [`RUNBOOK.md`](../../../RUNBOOK.md)：命令、binary pipeline 输入、失败恢复、性能和开发验证。
- [`runtime_config.example.json`](../../../runtime_config.example.json)：完整运行配置示例。
- [`binary_pipeline_config.example.json`](../../../binary_pipeline_config.example.json)：高级集成或离线重放输入示例。

运行日志、耗时与缓存属于观测信息；除非它们证明输入或分析覆盖不完整，否则不能单独改变分析结论。

# 当前系统文档

本目录描述系统当前是什么，以及实现不能破坏的产品、架构、契约、运维和质量边界。这里的“当前”表示文档语义生效，不等于每个可选能力都已在所有环境验证或发布。

## 阅读路径

1. [产品定位与能力边界](product/README.md)
2. [架构文档](architecture/README.md)
3. [跨步骤契约](contracts/README.md)
4. [运行与结果阅读](operations/README.md)
5. [质量与测试](quality/README.md)

## 唯一所有者

| 问题 | 文档所有者 |
|---|---|
| 系统为谁解决什么问题、明确不做什么 | `product/` |
| Step0～Step6 职责、binary-first 数据流和内部边界 | `architecture/` |
| 跨步骤字段、状态、诊断和交互语义 | `contracts/` 以及根目录运行时合同 |
| 如何运行、恢复和阅读输出 | `operations/` 以及根目录 `RUNBOOK.md` |
| 不可突破的质量下限、门禁和测试策略 | `quality/` |

局部函数、私有状态和实现细节优先由代码与测试定义。只有会影响调用方、分析结论、恢复语义或跨模块一致性的内容才在这里重复声明。
